Business Report Calculation Logic Documentation

Overview

This document explains how the business report calculates profit/loss, commission, and net amounts for different user types and commission structures.

Key Concepts:

  • Winning Team Total: What we PAY OUT (liability) - calculated from winning team entries
  • Losing Team Total: What we RECEIVE (asset) - calculated from losing team entries
  • Profit/Loss: Losing Team Total - Winning Team Total (positive = profit, negative = loss)
  • Cut Type Users: Users with reversed win/loss calculation logic

1. Entry Calculation Logic (Normal Users)

Step 1: Parse Entry Amounts

Entries are stored as formatted strings like "90/500000" where:

  • First part (90) = Rate percentage
  • Second part (500000) = Bet amount

Step 2: Calculate Team Totals

For each entry, calculate based on winning team and favorite/non-favorite status:

If Team 1 Wins: If favourite_team === 'team1': winningTeamFav += (team1Rate / 100) × team1FavAmount losingTeamNonFav += (team2Rate / 100) × team2NfavAmount If favourite_team === 'team2': winningTeamNonFav += team1NfavAmount losingTeamFav += team2FavAmount If Team 2 Wins: If favourite_team === 'team2': winningTeamFav += (team2Rate / 100) × team2FavAmount losingTeamNonFav += (team1Rate / 100) × team1NfavAmount If favourite_team === 'team1': winningTeamNonFav += team2NfavAmount losingTeamFav += team1FavAmount
Key Rules:
  • Winning Favorite: Rate% × Amount (e.g., 90% × 500,000 = 450,000)
  • Winning Non-Favorite: Just Amount (e.g., 500,000)
  • Losing Favorite: Just Amount (e.g., 500,000)
  • Losing Non-Favorite: Rate% × Amount (e.g., 90% × 500,000 = 450,000)

Step 3: Calculate Totals

winningTeamTotal = winningTeamFav + winningTeamNonFav
losingTeamTotal = losingTeamFav + losingTeamNonFav
profitLoss = losingTeamTotal - winningTeamTotal
Example:
  • Entry: "90/500000" on sl (Team 2) Non-Fav
  • Winner: zim (Team 1)
  • favourite_team = 'team1'
  • losingTeamNonFav = (90/100) × 500,000 = 450,000
  • winningTeamTotal = 0
  • losingTeamTotal = 450,000
  • profitLoss = 450,000 - 0 = 450,000 (profit)

2. Cut Type User Reversal Logic

Important: For cut type users (mark_as_cut === 'yes'), the calculation is REVERSED before applying commission.

Reversal Rules:

  • Winning entries → Treated as losing entries
  • Losing entries → Treated as winning entries
  • Favorite entries → Treated as non-favorite entries
  • Non-favorite entries → Treated as favorite entries
Reversal Logic: reversedWinningTeamFav = originalLosingTeamNonFav reversedWinningTeamNonFav = originalLosingTeamFav reversedLosingTeamFav = originalWinningTeamNonFav reversedLosingTeamNonFav = originalWinningTeamFav
Example (Cut User):
  • Entry: "90/500000" on sl (Team 2) Non-Fav
  • Winner: zim (Team 1)
  • Normal calculation:
    • losingTeamNonFav = 450,000
    • winningTeamTotal = 0
    • losingTeamTotal = 450,000
    • profitLoss = 450,000 (profit)
  • After reversal (cut user):
    • reversedWinningTeamFav = 450,000 (was losingTeamNonFav)
    • reversedLosingTeamNonFav = 0 (was winningTeamFav)
    • winningTeamTotal = 450,000
    • losingTeamTotal = 0
    • profitLoss = 0 - 450,000 = -450,000 (loss)

3. Commission Type: Profit/Loss

Calculation Logic:

function calculateRowResult(profitLoss, commissionPercent, partnershipPercent) { if (profitLoss > 0) { // CASE A: PROFIT commission = profitLoss × commissionPercent commissionAfterPartnership = commission × (1 - partnershipPercent) custNetWithComm = profitLoss × (1 - partnershipPercent) netProfitLoss = custNetWithComm - commissionAfterPartnership } else { // CASE B: LOSS commission = 0 commissionAfterPartnership = 0 custNetWithComm = profitLoss × partnershipPercent netProfitLoss = profitLoss × (1 - partnershipPercent) } }
Key Points:
  • Commission only applies when profitLoss > 0 (profit scenario)
  • No commission on losses
  • Partnership percentage splits the amount between customer and system
Example (Profit Scenario):
  • profitLoss = 450,000
  • commissionPercent = 4%
  • partnershipPercent = 20%
  • commission = 450,000 × 0.04 = 18,000
  • commissionAfterPartnership = 18,000 × (1 - 0.20) = 14,400
  • custNetWithComm = 450,000 × (1 - 0.20) = 360,000
  • netProfitLoss = 360,000 - 14,400 = 345,600
Example (Loss Scenario - Cut User):
  • profitLoss = -450,000 (after reversal)
  • commissionPercent = 4%
  • partnershipPercent = 20%
  • commission = 0 (no commission on loss)
  • commissionAfterPartnership = 0
  • custNetWithComm = -450,000 × 0.20 = -90,000
  • netProfitLoss = -450,000 × (1 - 0.20) = -360,000

4. Commission Type: Entrywise

Calculation Logic:

function calculateEntrywise(winningTeamTotal, losingTeamTotal, commissionPercent, partnershipPercent) { // Step 1: Calculate Gross Difference grossDifference = |winningTeamTotal - losingTeamTotal| isLosingTeamLarger = losingTeamTotal > winningTeamTotal sign = isLosingTeamLarger ? 1 : -1 // 1 = profit, -1 = loss // Step 2: Commission on Lost Side Total commission = losingTeamTotal × commissionPercent // Step 3: Net After Commission netAfterCommission = grossDifference - commission // Step 4: Apply Partnership custNetWithComm = netAfterCommission × partnershipPercent × sign netProfitLoss = netAfterCommission × (1 - partnershipPercent) × sign // Commission after partnership commissionAfterPartnership = commission × (1 - partnershipPercent) }
Key Points:
  • Commission is calculated on losingTeamTotal (what we receive)
  • Gross difference is always positive (absolute value)
  • Sign determines if it's profit (positive) or loss (negative)
  • Partnership is applied to net after commission
Example (Normal User - Profit):
  • winningTeamTotal = 0
  • losingTeamTotal = 450,000
  • commissionPercent = 4%
  • partnershipPercent = 20%
  • grossDifference = |0 - 450,000| = 450,000
  • isLosingTeamLarger = true → sign = 1 (profit)
  • commission = 450,000 × 0.04 = 18,000
  • netAfterCommission = 450,000 - 18,000 = 432,000
  • custNetWithComm = 432,000 × 0.20 × 1 = 86,400
  • netProfitLoss = 432,000 × 0.80 × 1 = 345,600
  • commissionAfterPartnership = 18,000 × 0.80 = 14,400
Example (Cut User - Loss after reversal):
  • winningTeamTotal = 450,000 (reversed)
  • losingTeamTotal = 0 (reversed)
  • commissionPercent = 4%
  • partnershipPercent = 20%
  • grossDifference = |450,000 - 0| = 450,000
  • isLosingTeamLarger = false → sign = -1 (loss)
  • commission = 0 × 0.04 = 0
  • netAfterCommission = 450,000 - 0 = 450,000
  • custNetWithComm = 450,000 × 0.20 × (-1) = -90,000
  • netProfitLoss = 450,000 × 0.80 × (-1) = -360,000
  • commissionAfterPartnership = 0 × 0.80 = 0

5. Commission Type: No Commission

Calculation Logic:

if (commissionType === 'no_commission') { partnershipRate = partnershipPercent / 100 totalCommission = 0 custNetWithComm = profitLoss × (1 - partnershipRate) netProfitLoss = profitLoss × (1 - partnershipRate) }
Key Points:
  • No commission is applied
  • Only partnership percentage is used
  • Both custNetWithComm and netProfitLoss use the same formula
Example (Cut User - Loss after reversal):
  • profitLoss = -450,000 (after reversal)
  • partnershipPercent = 20%
  • totalCommission = 0
  • custNetWithComm = -450,000 × (1 - 0.20) = -360,000
  • netProfitLoss = -450,000 × (1 - 0.20) = -360,000

6. Complete Flow Diagram

Step 1: Parse all entries for a user
  • Extract amounts from formatted strings (e.g., "90/500000")
  • Identify favorite team and rates
Step 2: Calculate team totals
  • Loop through each entry
  • Calculate winningTeamFav, winningTeamNonFav, losingTeamFav, losingTeamNonFav
  • Apply rate multiplication based on favorite/non-favorite and win/loss status
Step 3: Check if cut type user
  • If mark_as_cut === 'yes': Apply reversal logic
  • Swap winning/losing and favorite/non-favorite totals
Step 4: Calculate profit/loss
  • winningTeamTotal = finalWinningTeamFav + finalWinningTeamNonFav
  • losingTeamTotal = finalLosingTeamFav + finalLosingTeamNonFav
  • profitLoss = losingTeamTotal - winningTeamTotal
Step 5: Apply commission based on type
  • profit_loss: Use calculateRowResult(profitLoss, ...)
  • entrywise: Use calculateEntrywise(winningTeamTotal, losingTeamTotal, ...)
  • no_commission: Apply only partnership percentage
